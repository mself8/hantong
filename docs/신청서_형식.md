# 신청서 형식과 대시보드 API

대시보드는 이 문서의 API만 쓰면 된다. 서버 주소는 Railway에 올린 뒤 알려 준다. 로컬에서는 `http://localhost:8000`이고, `/docs`에서 API를 직접 눌러 볼 수 있다.

## 흐름

1. 어르신이 전화한다. 통화가 끝나면 Vapi가 통화 기록을 서버로 보낸다.
2. 서버가 신청서를 `processing`(정리 중)으로 먼저 저장하고, 몇 초 안에 항목을 채워 `pending`(확인 대기)으로 바꾼다.
3. 공무원이 대시보드에서 `approved`(승인)나 `held`(보류)로 처리한다.

## API

| 할 일 | 요청 |
|---|---|
| 목록 | `GET /api/requests` (상태로 거르기: `?status=pending`) |
| 상세 | `GET /api/requests/{id}` |
| 승인 | `POST /api/requests/{id}/approve` 본문 `{"memo": "서울정형외과로 확인"}` (memo는 생략 가능) |
| 보류 | `POST /api/requests/{id}/hold` 본문 `{"memo": "날짜 다시 확인"}` |
| 상태 이름 | `GET /api/statuses` → `{"processing": "정리 중", "pending": "확인 대기", "approved": "승인", "held": "보류"}` |
| 글로 시험 | `POST /api/requests` 본문 `{"text": "어르신: 담주 화요일 읍내 정형외과요"}` → 만든 신청서를 돌려준다 |
| 병원 목록 | `GET /api/hospitals?q=정형` |
| 마을 목록 | `GET /api/villages` (리별 65세 이상 인구와 비율 포함) |

목록은 최근 신청이 먼저 온다. 새 신청을 보려면 5초마다 목록을 다시 불러오면 된다.

## 신청서 필드

- `id`, `created_at`(한국 시각), `status`, `source`(`phone` 전화 / `text` 글 시험)
- `call`: 통화 정보. `caller`는 가린 번호(`010-****-5678`), `recording_url`은 녹음 주소
- `resident`: 가상 명부에서 찾은 어르신. 못 찾으면 `null` → 화면에 '명부 확인 필요'
- `transcript`: 통화 기록. `role`은 `elder`(어르신) / `ai`
- `intent`: `hospital_visit` 병원 가는 날 / `medication` 복약 문의 / `cancel` 취소 / `companion` 동행 문의 / `other`
- `summary`: 한 줄 요약
- `hospital`: `query`(어르신이 말한 표현), `department`, `status`(`matched` 한 곳 / `candidates` 여러 곳 / `unknown` 못 찾음), `candidates`(실제 기관 목록에서 고른 후보, 최대 5곳)
- `visit`: `date_expr`(말한 표현), `date`(YYYY-MM-DD), `date_source`(`rule` 규칙 계산 / `ai`), `time_expr`, `time`(HH:MM)
- `companion`: `needed`(`yes` / `no` / `unknown`), `reason`
- `pickup`: `village`(맞춘 리), `village_code`, `point`(명부의 승차 지점)
- `evidence`: 항목별 근거가 된 어르신 말. 화면에서 각 항목 옆에 보여 준다
- `checks`: 규칙 점검 결과. `level`이 `warn`이면 빨간색, `info`면 회색으로 보여 준다
  - `hospital_unclear` 병원 미확정, `date_unclear` 날짜 미확정, `date_past` 지난 날짜, `holiday` 공휴일, `sunday` 일요일
  - `clinic_closed` 진료 안 하는 날·시간, `hours_unknown` 진료시간 정보 없음, `far` 홍천 밖 병원
  - `companion_deadline` 병원동행 7일 전 예약 마감, `village_mismatch` 명부와 다른 마을, `date_mismatch` 날짜 계산 엇갈림
  - `extract_failed` 자동 정리 실패 → 통화 기록을 보고 직접 처리
- `memo`: 공무원 메모
- `history`: 상태가 바뀐 기록 `[{at, status, note}]`

## 화면에서 꼭 보여 줄 것

- 목록: 상태, 받은 시각, 어르신(마을), 한 줄 요약, 경고 개수
- 상세: 항목마다 값과 근거 발화를 나란히, 병원 후보 중 하나 고르기, 경고, 통화 기록 전문, 녹음 듣기
- 승인·보류 버튼과 메모
