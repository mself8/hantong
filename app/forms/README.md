# 공식 신청서 양식 (값을 채워 PDF로 내려받는 틀)

|---|---|---|
| 통합지원_신청서.pdf | 「의료·요양 등 지역 돌봄의 통합지원에 관한 법률 시행규칙」 [별지 제1호서식] (2026. 3. 20. 개정) PDF 원본 그대로 | 국가법령정보센터, 2026-11-19 |
| 특별교통수단_등록신청서.pdf | 「홍천군 교통약자의 이동편의 증진에 관한 조례」 [별지 제1호서식] 특별교통수단 등 이용대상자 등록 신청서. 원본은 한글(HWP)이라 hwp5odt → LibreOffice로 PDF 변환(앞쪽이 두 장으로 나뉨) | 국가법령정보센터, 2026-11-19 |

| 통합지원_신청서.docx | 위 서식의 한글(HWP) 원본(국가법령정보센터 flSeq=162492369)을 워드로 바꾼 틀 | 2026-11-20 |
| 특별교통수단_등록신청서.docx | 위 조례 서식 한글(HWP) 원본을 워드로 바꾼 틀 | 2026-11-20 |

- 워드 틀 만들기: HWP → ODT(pyhwp, ODF 스키마 검사 생략) → DOCX(LibreOffice). 값 채우기는 `app/wordforms.py`. 이 서버의 글꼴로 열면 쪽수가 늘어 보일 수 있다(한글 글꼴이 있는 PC에서는 원본에 가깝다).
- 희망택시(이장이 전화로 요청)와 병원동행(노인복지관 전화 예약)은 주민용 공식 신청서가 없어 신청서를 만들지 않는다(대시보드에서 '기관에 요청할 것'으로 보여 준다).
- 채우는 코드는 `app/pdfforms.py`. 칸 위치는 양식의 글자('성명', '주소' 등) 위치를 기준으로 잡았다.
